## 2026-07-22 — v0.1.0 초기 스펙 확정

### 요구사항 (사용자)
- 국장·미장 뉴스 통합 정리 사이트
- 주요 뉴스 매일 장 시작 전 휴대폰 전송 (국장/미장 각각)
- 종목별 차트 + **차트 등락일에 어떤 뉴스가 있었는지 한눈에**
- 시장 경제 흐름을 알 수 있는 양질의 정보
- 주식 초보도 아주 보기 쉬운 UI/UX
- 유료 주식 사이트 수준

### 결정 사항
| 항목 | 결정 | 근거 |
|---|---|---|
| 알림 채널 | **텔레그램 봇** | 무료·즉시 푸시·서식 지원. 카카오는 OAuth 토큰 2개월 갱신 부담 |
| 실행 환경 | **GitHub Actions + Vercel** | PC 꺼져 있어도 자동 실행. 비용 0원 |
| 뉴스 요약 | **Claude API** (`claude-haiku-4-5-20251001`) + 규칙기반 폴백 | 초보용 해설 품질이 핵심 차별점 |
| 저장소 | **정적 JSON을 레포에 커밋** | DB·백엔드 서버 불필요. 히스토리는 git이 관리 |
| 차트 | **lightweight-charts v5** | 무료·45KB·마커 API 지원 |
| 색상 | **상승=빨강 / 하락=파랑 (한국식)** 통일 | 국내 사용자 기준. 설정에서 미국식 전환 가능 |
