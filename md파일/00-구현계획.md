## 1. 무엇을 만드는가

| # | 요구사항 (사용자 원문) | 구현 방식 |
|---|---|---|
| R1 | 국장·미장 뉴스를 한번에 읽어서 정리 | 20개+ RSS 소스 수집 → 중복제거 → 종목/테마 태깅 → 통합 뉴스 피드 |
| R2 | 주요 뉴스를 모바일로 전송 | 텔레그램 봇 푸시 (HTML 서식, 종목 링크 포함) |
| R3 | 매일 장 시작 전 전송 (국장/미장 각각) | GitHub Actions cron 2개 — KR 07:30 KST / US 21:30 KST |
| R4 | 국장·미장 종목별 주식 데이터(차트) | FinanceDataReader 기반 2년치 일봉 OHLCV + 지표 |
| R5 | **차트가 오르내린 날 어떤 뉴스가 있었는지 차트에서 한눈에** | ⭐ 핵심기능. 이벤트 탐지 → 뉴스 매칭 → LLM 원인 요약 → 차트 마커 |
| R6 | 시장 경제 흐름을 알 수 있는 양질의 정보 | 지수·환율·금리·유가·VIX 매크로 대시보드 + 섹터 히트맵 + 수급 |
| R7 | 주식 초보도 아주 보기 쉬운 UI/UX | 용어 툴팁 사전, 도움말 탭, 신호등 색상, 3줄 요약 우선 |
| R8 | 유료 사이트 수준 | 위 전부 + 워치리스트, 종목 검색, 다크모드, 모바일 우선 반응형 |

### ⭐ R5 = 이 프로젝트의 차별점

일반 사이트는 "차트"와 "뉴스"가 따로 논다. 여기서는 **연결**한다.

```
일봉 데이터 → 이상 변동일 탐지(급등/급락/거래량폭발/갭)
           → 그 날짜 ±1일 뉴스 수집 (종목명 매칭)
           → Gemini가 "이 날 왜 움직였나" 2~3문장 해설 + 신뢰도
           → 차트 위 ▲▼ 마커로 렌더 → 클릭하면 원인 + 원문 링크
```

## 2. 아키텍처 (서버 0원)

```
┌──────────────── GitHub Actions (cron) ─────────────────┐
│  brief-kr.yml   22:30 UTC (Sun–Thu) = 07:30 KST 평일   │
│  brief-us.yml   12:30 UTC (Mon–Fri) = 21:30 KST 평일   │
│  data-sync.yml  07:30 / 21:30 UTC   = 장 마감 후 2회   │
└───────────────────────┬────────────────────────────────┘
                        │ python -m pipeline.run
        ┌───────────────┴───────────────┐
        ▼                               ▼
  [수집] 가격 · 뉴스 · 매크로      [분석] 이벤트 · 매칭 · LLM요약
        └───────────────┬───────────────┘
                        ▼
              data/**.json  (레포에 커밋)
                 │                    │
                 ▼                    ▼
        [알림] 텔레그램 봇      [웹] Vercel 정적 배포
         → 사용자 휴대폰         → React + lightweight-charts
```

**정적 JSON 전략**: DB·백엔드 서버 없음. 파이프라인이 JSON을 만들어 레포에 커밋하고, 웹은 그걸 fetch한다. 비용 0원, 장애 포인트 최소, 히스토리는 git이 관리.

### 기술 스택

| 레이어 | 선택 | 이유 |
|---|---|---|
| 파이프라인 | Python 3.12 | 금융 데이터 라이브러리 생태계 |
| 가격 데이터 | FinanceDataReader | 국장·미장·지수·환율 단일 API, 무료, 키 불필요 |
| 뉴스 | feedparser (RSS) | 크롤링보다 안정·합법·가벼움 |
| 요약·번역 | Google Gemini (`gemini-2.5-flash`, 무료 티어) | 이벤트 해설 + 해외뉴스 자동 번역. 규칙기반/원문 폴백 내장 |
| 프론트 | React 19 + Vite + TypeScript | |
| 차트 | lightweight-charts v5 | TradingView 제작, 무료, 마커 API 지원, 45KB |
| 스타일 | Tailwind CSS v4 | |
| 배포 | Vercel (웹) + GitHub Actions (배치) | 무료 티어로 충분 |
| 알림 | Telegram Bot API | 무료·즉시 푸시·서식 지원 |

## 3. 구현 단계

## 6. 성공 기준

1. 매일 아침 07:30 / 밤 21:30에 텔레그램 브리핑이 **자동으로** 온다.
2. 종목 페이지에서 급등락일 마커를 누르면 **그 날 무슨 일이 있었는지** 바로 읽힌다.
3. 주식 용어를 모르는 사람이 홈 화면만 봐도 **오늘 시장 분위기**를 안다.
4. 전체 운영 비용 **0원** (Gemini 무료 티어 + Actions/Vercel 무료 한도 내).

## 7. 명시적 비목표 (하지 않는 것)

- ❌ 매수/매도 추천, 목표가 제시 → 투자자문업 규제 영역. 사실 전달만 한다.
- ❌ 실시간(초단위) 시세 → 무료 소스로 불가능. 일봉 + 지연 시세 기준.
- ❌ 자동매매 연동
- ❌ 로그인/회원 시스템 → 개인용 단일 사용자. 워치리스트는 브라우저 localStorage.
