# UI/UX 설계 — "주식 초보도 아주 보기 쉽게"

## 0. 설계 원칙 5가지

| # | 원칙 | 실제 적용 |
|---|---|---|
| 1 | **결론 먼저, 숫자 나중** | 모든 화면 최상단은 문장. 숫자 테이블은 그 아래. |
| 2 | **모르는 단어가 나오면 그 자리에서 해결** | 전문용어에 점선 밑줄 → 탭/호버하면 쉬운 설명 팝오버 |
| 3 | **색으로 먼저 읽히게** | 빨강(상승)/파랑(하락) — **한국식**. 미장도 동일하게 통일 |
| 4 | **초보에게 필요 없는 건 숨긴다** | `초보 모드` 기본 ON → RSI·z-score 등 고급 지표 숨김 |
| 5 | **차트는 설명이 붙어야 차트다** | 급등락일에 마커. 마커 없는 차트는 초보에겐 그냥 그림 |

> **색상 주의**: 한국 사용자 기준 **상승=빨강, 하락=파랑**으로 통일한다.
> 미국식(상승=초록)과 반대라 섞으면 혼란 → 전 화면 한 가지 규칙만 쓴다.
> 설정에서 `미국식 색상`으로 바꿀 수 있게 한다.

```

├─ /market/KR         국장 — 지수·섹터·등락상위·수급
```

**마커 규칙**
| 요소 | 규칙 |
|---|---|
| 모양 | 급등 `arrowUp`(빨강, 봉 위) / 급락 `arrowDown`(파랑, 봉 아래) / 거래량폭발 `circle`(주황) |
| 크기 | severity 1→`small` · 2→`normal` · 3→`large` |
| 라벨 | `headline` 최대 12자 + `…` (차트가 지저분해지지 않게) |
| 클릭 | 하단 이벤트 카드로 스크롤 + 하이라이트 |
| 초보모드 ON | severity ≥ 2만 표시 (마커 과밀 방지) |

**차트 분석 카드 규칙** (schema §4 `analysis`)

| 요소 | 규칙 |
|---|---|
| 주인공 | 점수가 아니라 **행동 문구**(`actionLabel`). 점수는 곁들이로 우측 상단 |
| 색 | 강세=상승색 / 약세=하락색 / 중립=muted. **색만으로 구분하지 않는다** — ▲▼― 기호를 항상 같이 |
| 근거 | 기법 11가지를 한 줄씩. 누르면 `detail`(왜 그렇게 읽는지)이 펼쳐진다 |
| 초보모드 ON | 방향이 잡힌 지표 4개만. "전체 11개 보기" 버튼으로 확장 |
| 면책 | 카드 하단에 `disclaimer` **항상** 노출 + `/learn?tab=chart` 링크 |
| 지표 토글 | 6개(뉴스마커·이동평균·볼린저·MACD·RSI·지지저항). 기본은 뉴스마커·지지저항만 ON. 모바일에서 줄이 넘치므로 가로 스크롤 |
| 범례 | 켠 지표를 **색 견본**으로 (색 이름을 글로 적지 않는다 — 초보는 "주황 5일선"을 읽고도 화면에서 못 찾는다). 패널별로 줄을 나눈다: `가격` / `MACD 패널` / `RSI 패널` |
| 보조 패널 | MACD·RSI는 가격과 단위가 달라 lightweight-charts 의 별도 pane. 켠 만큼 차트 높이가 늘어난다 |

### 2-3. 시장 `/market/KR`

- 지수 카드(코스피/코스닥) + 30일 미니차트
- **섹터 히트맵**: 타일 크기=시총, 색=등락률. 탭하면 해당 섹터 종목
- 등락 상위/하위 10 — 각 종목 옆에 **"왜 올랐나" 한 줄** (이벤트 요약 재사용)
- 매크로 바: 환율·금리·유가·VIX

### 2-4. 뉴스 `/news`

- 필터 칩: `전체 | 국장 | 미장 | 정책·금리 | 실적 | 산업`
- 카드: 제목 / 매체 / 시간 / **관련 종목 뱃지** / 중요도 별
- 중요도 상위는 상단 고정 + 붉은 테두리
- 무한스크롤

### 2-5. 도움말 `/learn` — 탭 2개

탭 상태는 쿼리스트링(`?tab=chart`)에 둔다. 분석 카드에서 링크로 바로 착지해야 하기 때문.

**📖 용어사전** (`/learn`)
- 툴팁의 "더 알아보기" 착지점
- 카테고리: 기본용어 / 차트보는법 / 시장구조 / 거시경제 / 실적·이벤트
- 각 항목: 한 줄 정의 → 비유 설명 → "그래서 뭘 보면 되나"

**📊 차트분석** (`/learn?tab=chart`)

읽는 순서를 맨 위에 박아 둔다 — 초보자는 어디서부터 봐야 할지를 제일 먼저 막힌다.

| 절 | 내용 |
|---|---|
| 봉 읽는 법 | 양봉/음봉 해부도 1장. 시가·종가·고가·저가가 어디인지 |
| 지표 색 약속 | `INDICATOR` 8종을 **색 견본 + 이름 + "그래서 뭘 보는 선인지"**로. 종목 차트와 같은 색이라는 걸 여기서 못박는다 |
| 기법 11가지 | 종목 화면 "기법별 판정"과 **같은 이름·같은 순서**. 각 항목: 무엇을 재나 → 예시 차트 → 강세/약세로 읽는 법 → **언제 틀리나** |
| 신호가 만들어지는 방법 | 가중 합산 → 점수 구간 표 → 행동 문구를 따로 두는 이유 |
| 행동 신호 8가지 | 각각 "언제 뜨나 / 주의" 2줄 |
| 꼭 알아둘 한계 | 후행지표 · 횡보장 · 재료 미반영 · 추천 아님 |

**예시 차트는 이미지가 아니라 SVG로 그린다** (`components/PatternChart.tsx`).
캡처 이미지는 ①다크/라이트 테마에서 어색해지고 ②폭이 줄면 글씨가 뭉개지며
③실제 차트 색이 바뀌면 조용히 어긋난다. 값 배열을 두고 이동평균·볼린저·RSI·
MACD·스토캐스틱을 **실제 공식으로 계산해서** 그리므로, 종목 화면에서 지표를
켰을 때와 모양도 색도 같다.

**캔들로 그린다.** 종가만 이은 선은 "봉을 어떻게 읽는가"를 가르치는 페이지의
그림으로는 앞뒤가 맞지 않는다. 다만 캔들은 폭이 필요해서 — 시리즈는 **130봉으로
계산하고 마지막 55봉만 그린다**(`VIS`). 60일선은 60봉을 먹고 나서야 시작하므로
짧은 시리즈를 통째로 그리면 60일선이 오른쪽 3분의 1에만 나타나고, 반대로 130봉을
다 그리면 봉 하나가 2px 실선이 된다. 종목 화면이 기간 칩으로 하는 일과 같다.

마커는 눈대중으로 박지 않는다. 골든크로스·MACD 교차·돌파 지점은 **같은 공식으로
찾아서**(`crossIndex`, `firstAbove`) 좌표를 얻는다 — 파형을 조금만 손봐도 점선이
엉뚱한 데 찍히기 때문이다. 지지·저항 가로선도 보이는 구간의 실제 고·저에서 뽑는다.

## 3. 초보자 배려 장치

### 3-1. 용어 툴팁 (`<Term>` 컴포넌트)

```tsx
<Term k="per">PER</Term>
// → 점선 밑줄 + 탭하면 팝오버
// "주가가 회사가 버는 돈의 몇 배인지. 10배면 지금 이익이 10년 쌓여야 주가만큼 됩니다.
//  낮을수록 싸다고 보지만, 성장 기대가 없어서 낮은 경우도 많아요."
```

사전은 `web/src/lib/terms.ts` 한 곳. 등록 용어(초기 40개):
PER · PBR · ROE · EPS · 시가총액 · 거래량 · 거래대금 · 이동평균선 · 골든크로스 · 데드크로스 · RSI · 변동성 · VIX · 외국인수급 · 기관수급 · 공매도 · 배당수익률 · 코스피 · 코스닥 · S&P500 · 나스닥 · 다우 · 환율 · 기준금리 · 국채금리 · 장단기금리차 · 인플레이션 · FOMC · 어닝서프라이즈 · 가이던스 · 시간외거래 · 서킷브레이커 · 상한가 · 갭상승 · 지지선 · 저항선 · ETF · 우선주 · 액면분할 · 유상증자

### 3-2. 초보 모드 토글 (헤더 우측 고정)

| | 초보 모드 ON (기본) | OFF |
|---|---|---|
| 차트 지표 | 종가선 + 이동평균 20일만 | 캔들 + MA5/20/60 + RSI + 거래량 |
| 마커 | severity ≥ 2 | 전부 |
| 숫자 표기 | `1,554조원` | `1,554,000,000,000,000` |
| 고급 필드 | z-score·volumeRatio 숨김 | 표시 |
| 문구 | "많이 올랐어요" | "+5.24% (2.8σ)" |

### 3-3. 숫자 사람 말로 바꾸기 (`format.ts`)

```
1554000000000000 → "1,554조원"
0.82             → "평소의 0.8배"
+5.24%           → "+5.24%" + 뱃지 "많이 올랐어요"
2.81 (z-score)   → "최근 3달 중 손에 꼽는 움직임"
```

## 4. 반응형 / 접근성

| 브레이크포인트 | 레이아웃 |
|---|---|
| < 640px (모바일 기준) | 1열, 하단 탭바, 차트 높이 260px, 가로 스크롤 금지 |
| 640–1024px | 2열 그리드 |
| > 1024px | 좌측 사이드바 + 3열, 차트 높이 460px |

- 명도 대비 WCAG AA (4.5:1) 이상
- 색맹 대비: 색 + **화살표 기호(▲▼)** 동시 사용 — 색만으로 정보 전달 금지
- 모든 인터랙션 요소 최소 44×44px 터치 타겟
- 다크모드: `prefers-color-scheme` 자동 + 수동 토글
