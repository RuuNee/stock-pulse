# 데이터 스키마 — 파이프라인 ↔ 웹 계약

파이프라인은 `data/` 아래 정적 JSON을 만들고, 웹은 그것만 읽는다.
**이 문서가 유일한 계약**이다. 스키마를 바꾸면 여기부터 고치고 양쪽을 맞춘다.

웹은 `/data/...` 경로로 읽는다. 배포 빌드에서는 `data/` → `web/public/data/`로 복사되고,
dev 서버에서는 복사 없이 레포 `data/`를 직접 서빙한다(스펙 §8.1).

```
data/
├─ manifest.json                 # 생성 시각 · 파일 목록 · 무결성
├─ market/overview.json          # 매크로 대시보드
├─ tickers/index.json            # 종목 목록 (검색·리스트용, 가벼움)
├─ tickers/KR/005930.json        # 종목 상세 (차트 + 이벤트 마커)
├─ tickers/US/AAPL.json
├─ news/latest.json              # 통합 뉴스 피드
└─ brief/latest-KR.json          # 최신 장전 브리핑 (텔레그램과 동일 내용)
   brief/latest-US.json
   brief/2026-07-22-KR.json      # 날짜별 아카이브
```

---

## 1. `manifest.json`

```jsonc
{
  "version": 1,
  "generatedAt": "2026-07-22T22:30:11Z",   // UTC ISO8601
  "generatedAtKst": "2026-07-23 07:30",
  "counts": { "tickers": 60, "news": 412, "events": 287 },
  "markets": {
    "KR": { "lastTradingDay": "2026-07-22", "briefDate": "2026-07-23" },
    "US": { "lastTradingDay": "2026-07-21", "briefDate": "2026-07-22" }
  }
}
```

## 2. `market/overview.json`

홈 화면 매크로 대시보드용.

```jsonc
{
  "generatedAt": "2026-07-22T22:30:11Z",
  "indices": [
    {
      "key": "KS11",
      "name": "코스피",
      "market": "KR",              // KR | US | GLOBAL
      "group": "index",            // index | fx | rate | commodity | crypto
      "date": "2026-07-31",        // 이 값이 어느 날 마감인지. 장중 스냅샷은 싣지 않는다
      "value": 6797.7,
      "change": -12.4,
      "changePct": -0.18,
      "unit": "pt",                // pt | KRW | USD | % | bp
      "spark": [6710.2, 6733.1, ...],   // 최근 30거래일 종가
      "beginnerNote": "한국 대표 기업 모음의 평균 성적표"   // 초보 툴팁
    }
  ],
  "sectors": {                     // 섹터 히트맵
    "KR": [ { "name": "반도체", "changePct": 1.8, "count": 12, "topName": "SK하이닉스", "topPct": 3.4 } ],
    "US": [ { "name": "Technology", "changePct": -0.6, "count": 9, "topName": "NVDA", "topPct": 1.2 } ]
  },
  "movers": {                      // 등락 상위
    "KR": { "up": [MoverRef], "down": [MoverRef] },
    "US": { "up": [MoverRef], "down": [MoverRef] }
  },
  "marketMood": {                  // 신호등
    "KR": { "score": 42, "label": "중립", "color": "amber", "reason": "지수는 소폭 하락했지만 거래대금은 평소 수준" },
    "US": { "score": 61, "label": "양호", "color": "green", "reason": "3대 지수 상승, VIX 16선 안정" }
  }
}
```

`MoverRef`: `{ "code": "005930", "name": "삼성전자", "market": "KR", "changePct": 3.2, "close": 260500, "reason": "이벤트 요약 한 줄 또는 null" }`

**marketMood.score** 0~100 산출식 (`analyze/mood.py`):
`지수등락(40%) + 상승종목비율(25%) + VIX역방향(15%) + 거래대금비(10%) + 외국인/환율(10%)`
→ 0-34 `위축(red)` / 35-64 `중립(amber)` / 65-100 `양호(green)`

## 3. `tickers/index.json`

검색·리스트 렌더용. 종목당 최소 필드만 (전체 60종목 ≈ 20KB).

```jsonc
{
  "generatedAt": "...",
  "items": [
    {
      "code": "005930",           // 국장=6자리 숫자, 미장=티커
      "name": "삼성전자",
      "nameEn": "Samsung Electronics",
      "market": "KR",             // KR | US
      "exchange": "KOSPI",        // KOSPI | KOSDAQ | NASDAQ | NYSE
      "sector": "반도체",
      "currency": "KRW",
      "close": 260500,
      "changePct": -0.57,
      "marcap": 1554000000000000,  // 시가총액 (원/달러)

        "date": "2026-07-29"
      }
    }
  ]
}
```

## 4. ⭐ `tickers/{KR|US}/{code}.json` — 핵심 파일

```jsonc

  "name": "삼성전자",
  "market": "KR",
  "exchange": "KOSPI",
  "sector": "반도체",
  "currency": "KRW",
  "updatedAt": "2026-07-22T22:30:11Z",

  "quote": {

  "ohlcv": {
    "columns": ["d", "o", "h", "l", "c", "v"],
    "rows": [

  "indicators": {

    "ma20": [...],
    "ma60": [...],
    "ma120": [...],
    "rsi14": [...],
    "volMa20": [...],
    "bbUpper": [...],      // 볼린저밴드 20일 ±2σ
    "bbLower": [...],
    "macd": [...],         // 12/26 EMA 차이
    "macdSignal": [...],   // 위 값의 9일 EMA
    "macdHist": [...]      // macd - macdSignal
  },

  // ⭐ 차트 분석 = 기술적 분석 기법 11가지의 마지막 봉 기준 판정.
  //    순수 계산이라 LLM 예산을 쓰지 않는다. 이력이 TA_MIN_BARS 미만이면 null.
  "analysis": {
    "date": "2026-07-29",             // 판정 기준 거래일 (= 마지막 봉)
    "score": -28,                     // 가중 합산 -100 ~ +100
    "signal": "sell",                 // 점수 구간 라벨 (config.TA_SIGNAL_BANDS)
    "label": "매도 우위",
    "action": "reduce",               // chase 추격 | addBuy 추가매수(눌림목)
                                      // | buy 매수전환 | takeProfit 차익실현
                                      // | reduce 비중축소 | stopLoss 손절유의
                                      // | rebound 반등확인 | hold 관망
    "actionEmoji": "📉",
    "actionLabel": "비중 축소 신호",
    "actionNote": "추세 지표가 아래를 향합니다. ...",   // 그 신호를 어떻게 읽는지
    "headline": "역배열 · 중기 상승추세 · 데드크로스 발생",  // 목록용 한 줄
    "summary": "11가지 차트 기법 중 강세 4개 · 약세 7개로 종합 -28점입니다. ...",

    "trend": {
      "phase": "역배열",               // 정배열 | 역배열 | 혼조(중기선 위/아래)
      "direction": "down",            // up | down | flat
      "slopePct": -3.2,               // 60일선의 20거래일 변화율
      "label": "역배열 · 중기 하락추세",
      "aboveMa60": false

    "counts": { "bullish": 4, "bearish": 7, "neutral": 0 },

    // 기법 11가지. 순서 고정 — 웹 도움말(chartGuide.ts)이 같은 key를 쓴다.

    // · stochastic · volume · breakout · levels
    "signals": [
      {
        "key": "maCross",
        "name": "데드크로스 발생",
        "group": "추세",              // 추세 | 모멘텀 | 변동성 | 수급 | 가격대
        "verdict": "bearish",         // bullish | bearish | neutral
        "strength": 1.0,              // 0~1 — 가중치와 곱해 점수에 들어간다
        "weight": 3,                  // 1~3
        "value": "5거래일 전",         // 짧은 수치 표기 (한 줄에 붙는다)
        "detail": "5거래일 전 20일선이 60일선을 위에서 아래로 뚫었습니다. ..."
      }
    ],

    "levels": {
      // 스윙 피벗(최근 120봉) + 최근 20봉 고·저 중 현재가에 가장 가까운 값.
      // 한쪽에 후보가 없으면 null (신저가 종목엔 지지선이 없다).
      "support": 167300, "resistance": 209000,
      "supportGapPct": -19.8, "resistanceGapPct": 0.2,  // 현재가 대비
      "high52": 289000, "low52": 168500
    },
    "risk": { "atrPct": 2.26, "band": "보통" },  // 낮음|보통|높음|매우 높음
    "disclaimer": "차트 지표만 기계적으로 계산한 결과입니다. ..."
  },

  // ⭐ 차트 마커 = R5의 결과물
  "events": [
    {
      "id": "005930-2026-07-15",
      "date": "2026-07-15",
      "type": "surge",            // surge 급등 | plunge 급락 | volumeSpike 거래량폭발 | gapUp | gapDown
      "severity": 3,              // 1 주목 · 2 중요 · 3 매우중요 → 마커 크기
      "changePct": 5.24,
      "zScore": 2.81,             // 60일 수익률 표준편차 대비
      "volumeRatio": 3.1,         // 20일 평균 거래량 대비
      "close": 260500,

      "headline": "HBM4 엔비디아 공급 계약 체결",      // 마커 라벨 (≤30자)
      "explain": "삼성전자가 엔비디아에 차세대 HBM4 메모리를 공급하기로 했다는 소식이 나왔습니다. HBM은 AI 반도체에 꼭 필요한 고성능 메모리라서, 이 계약은 회사 이익이 늘어난다는 기대를 키웠습니다.",
      "confidence": "high",       // high | medium | low — 뉴스 근거 강도
      "source": "llm",            // llm | rule — 요약 생성 방식
      "tags": ["공급계약", "반도체", "AI"],
      "sentiment": "positive",    // positive | negative | neutral

      "news": [                   // 근거 기사 (최대 5건)
        {
          "title": "삼성전자, 엔비디아와 HBM4 공급 계약",
          "url": "https://...",
          "source": "연합뉴스",
          "publishedAt": "2026-07-15T08:12:00Z",
          "score": 0.91           // 관련도
        }
      ]
    }
  ],

  "recentNews": [ NewsItem ]      // 이벤트와 무관한 최신 종목 뉴스 10건
}
```

> **`explain` 작성 규칙**: 초보자 대상. 전문용어를 쓰면 반드시 그 자리에서 풀어쓴다.
> 2~3문장, 존댓말, 단정 금지("~로 보입니다"), **매수/매도 의견 금지**.
>
> **`analysis` 와의 경계**: `events[].explain` 은 *뉴스가 설명하는 원인*이고,
> `analysis` 는 *가격만 보고 읽은 차트 모양*이다. 둘은 근거가 달라서 섞지 않는다.
> `analysis.actionLabel` 이 "추격 매수 신호" 같은 매매 용어를 쓰는 것은 기술적
> 분석 교과서의 국면 이름을 그대로 옮긴 것이며, 권유가 아니라는 점을 `disclaimer`
> 로 함께 내보낸다. 웹은 이 문구를 **항상** 카드 안에 노출해야 한다.

## 5. `news/latest.json`

```jsonc
{
  "generatedAt": "...",
  "items": [ NewsItem ]           // 최근 3일, 최대 400건, 점수 내림차순
}
```

### `NewsItem`

```jsonc
{
  "id": "a1b2c3d4",               // url 정규화 후 sha1 앞 8자
  "title": "코스피, 알파벳 실적 앞두고 경계에 전강후약",
  "summary": "장 초반 상승 출발했으나 오후 들어 외국인 매도세에 밀려 하락 마감했습니다.",
  "url": "https://...",
  "source": "연합뉴스",
  "sourceKey": "yna_market",
  "market": "KR",                 // KR | US | GLOBAL
  "publishedAt": "2026-07-22T06:31:00Z",
  "category": "시장",             // 시장 | 종목 | 정책 | 산업 | 실적 | 국제 | 암호화폐
  "tags": ["코스피", "외국인수급"],
  "tickers": [                    // 매칭된 종목
    { "code": "005930", "name": "삼성전자", "market": "KR", "score": 0.8 }
  ],
  "importance": 78,               // 0~100, 브리핑 선별 기준
  "sentiment": "negative",
  "isTop": true                   // 장전 브리핑에 포함되었는가
}
```

**importance 산출** (`analyze/score.py`):
`매체가중치(30) + 최신성(20) + 유니버스종목언급(20) + 키워드가중치(20) + 중복보도수(10)`
키워드 가중치 예: 금리·FOMC·관세·실적발표·인수합병·공시 = 高

## 7. 규약

| 항목 | 규칙 |
|---|---|
| 시각 | 저장은 **UTC ISO8601 + `Z`**. 표시할 때만 KST/ET 변환 |
| 날짜 | 거래일은 해당 시장 현지 날짜 `YYYY-MM-DD` |
| 숫자 | `null` 허용. `NaN`/`Infinity` **금지** (JSON 파싱 실패) |
| 인코딩 | UTF-8, `ensure_ascii=false` |
| 결측 | 필드를 지우지 말고 `null`/`[]`로 채운다 (웹 방어코드 최소화) |
| 파일명 | 미장 티커는 대문자, 국장 코드는 6자리 문자열 (앞 0 유지) |
| 크기 | 종목 상세 1개당 300KB 이하 유지 (2년 일봉 + 지표 11종 기준 실측 ~112KB) |
