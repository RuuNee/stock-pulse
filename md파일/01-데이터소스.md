## 3. ⭐ 종목별 뉴스 — R5의 핵심 재료

차트 마커를 만들려면 "특정 종목 × 특정 날짜" 뉴스가 필요하다. 두 경로 모두 검증 완료.

### 3-1. 미장 — Yahoo Finance 티커 RSS

```
https://feeds.finance.yahoo.com/rss/2.0/headline?s={TICKER}&region=US&lang=en-US
```
✅ `AAPL` 호출 시 20건 반환. 티커 정확 매칭이라 노이즈 거의 없음.

### 3-2. 국장 — Google News RSS 검색

```
https://news.google.com/rss/search?q="{종목명}"+주가&hl=ko&gl=KR&ceid=KR:ko
```
✅ 검증 시 100건 반환. 국내 매체 전반을 종목명으로 훑는다.
날짜 범위는 `when:7d` 연산자로 제한 가능 → 과거 이벤트 보강 시 활용.

> **주의**: Google News RSS는 호출이 잦으면 429가 난다.
> → `config.py`의 `GOOGLE_NEWS_DELAY_SEC = 1.5`로 종목 간 간격을 둔다.

## 4. 수집 정책

| 항목 | 정책 |
|---|---|
| User-Agent | `Mozilla/5.0 (compatible; StockPulse/1.0)` 명시 |
| 타임아웃 | 피드당 15초 |
| 실패 처리 | 개별 소스 실패는 경고 로그 후 **계속 진행** (전체 중단 없음) |
| 중복 제거 | URL 정규화 + 제목 유사도(정규화 후 완전일치) |
| 캐시 | 유니버스/섹터 목록은 24시간 디스크 캐시 (`.cache/`) |
| 저작권 | 제목·요약 일부 + **원문 링크만** 저장. 본문 전문 저장/재배포 안 함 |
| robots | RSS는 배포 목적 피드이므로 크롤링 아님. HTML 스크래핑은 하지 않음 |
