# 운영 가이드

## 1. 처음 한 번만 — 사용자 작업 체크리스트

### ① 텔레그램 봇 만들기

1. 텔레그램에서 **@BotFather** → `/newbot` → 이름·아이디 입력
2. 받은 **토큰** 복사 (`8123456789:AAF...`)
3. 만든 봇과 대화방 열고 아무 메시지나 전송 (필수 — 안 보내면 chat_id를 못 읽음)
4. chat_id 확인:

```bash
python -m pipeline.run telegram-whoami --token 여기에토큰
```

### ② Anthropic API 키 발급

https://console.anthropic.com → API Keys → Create Key (`sk-ant-...`)

> 키가 없어도 파이프라인은 **규칙기반 요약으로 폴백**해서 정상 동작한다. 품질만 떨어진다.

### ③ GitHub 시크릿 등록

```bash
gh secret set TELEGRAM_BOT_TOKEN --repo RuuNee/stock-pulse
gh secret set TELEGRAM_CHAT_ID   --repo RuuNee/stock-pulse
gh secret set ANTHROPIC_API_KEY  --repo RuuNee/stock-pulse
```

(명령 실행 후 값을 붙여넣고 Enter)

### ④ 로컬 개발용 `.env`

레포 루트에 `.env` 생성 (`.gitignore`에 등록되어 커밋 안 됨):

```dotenv
TELEGRAM_BOT_TOKEN=8123456789:AAF...
TELEGRAM_CHAT_ID=123456789
ANTHROPIC_API_KEY=sk-ant-...
```

### ⑤ Vercel 배포

1. https://vercel.com → Add New Project → GitHub `RuuNee/stock-pulse` import
   (프라이빗 레포도 무료 플랜에서 연결된다)
2. 설정값 — 레포의 `vercel.json`이 이미 지정하고 있어 그대로 두면 된다:
   - Framework Preset: **Vite**
   - Root Directory: `web`
   - Build Command: `npm run build`
   - Output Directory: `dist`
3. Deploy → 발급된 도메인을 `pipeline/config.py`의 `SITE_URL`에 반영

## 2. 명령어

```bash
# 소스 헬스체크 — 어떤 데이터 소스가 살아있는지 확인
python -m pipeline.run doctor

# 전체 데이터 재계산 (가격 + 뉴스 + 이벤트 + 요약) → data/
python -m pipeline.run sync

# 특정 시장만
python -m pipeline.run sync --market KR

# 브리핑 만들기 (발송 안 함, 콘솔 출력)
python -m pipeline.run brief --market KR --dry-run

# 브리핑 만들고 텔레그램 발송
python -m pipeline.run brief --market KR --send

# 텔레그램 chat_id 조회
python -m pipeline.run telegram-whoami
```

```bash
# 웹 개발 서버
cd web && npm install && npm run dev
```

## 3. 자주 쓰는 조정

| 하고 싶은 것 | 고칠 곳 |
|---|---|
| 추적 종목 추가/삭제 | `pipeline/config.py` → `KR_UNIVERSE` / `US_UNIVERSE` |
| 브리핑 시간 변경 | `.github/workflows/brief-*.yml` → `cron` |
| 뉴스 소스 추가 | `pipeline/config.py` → `FEEDS` |
| 이벤트 민감도 조정 | `pipeline/config.py` → `EVENT_*` 임계값 |
| LLM 비용 줄이기 | `pipeline/config.py` → `LLM_MAX_EVENTS_PER_RUN` 낮추기 |
| 용어 사전 추가 | `web/src/lib/terms.ts` |
| 상승=초록으로 변경 | 사이트 설정 메뉴에서 `미국식 색상` 토글 |

## 4. 트러블슈팅

| 증상 | 원인 / 해결 |
|---|---|
| 텔레그램이 안 옴 | ① 봇과 대화를 먼저 시작했는지 ② 시크릿 오타 ③ Actions 로그 확인 ④ 휴장일이면 정상 동작 |
| `doctor`에서 피드 EMPTY | 해당 매체 RSS 폐지. `config.py` `FEEDS`에서 제거하고 [01-데이터소스.md](01-데이터소스.md) 갱신 |
| Google News 429 | 호출 과다. `GOOGLE_NEWS_DELAY_SEC` 상향 (기본 1.5초) |
| 이벤트 요약이 다 `rule` | `ANTHROPIC_API_KEY` 미설정/잔액부족. Actions 로그의 `[llm]` 라인 확인 |
| Actions에서 커밋 실패 | 레포 Settings → Actions → General → Workflow permissions → **Read and write** 체크 |
| 사이트에 옛날 데이터 | `data/` 커밋 후 Vercel 재배포됐는지 확인. 워크플로가 push하면 자동 트리거됨 |
| 종목 JSON이 없음 | `sync`가 실패했거나 유니버스에 없는 종목. Actions 로그 확인 |

## 5. 정기 점검 (월 1회 권장)

```bash
python -m pipeline.run doctor
```

- 죽은 피드 정리 → `config.py` + `01-데이터소스.md` 동시 갱신
- GitHub Actions 사용량 확인 (Settings → Billing)
- Anthropic 사용료 확인 (console.anthropic.com → Usage)
- `data/` 디렉터리 용량 — 1GB 넘으면 오래된 `brief/` 아카이브 정리
